Network Route API: checker

Runs 36 checks against the API and shows a pass or fail for each one. Nothing needs to be installed.

The live demo is on a free server that sleeps when idle. The first run can take up to a minute while it wakes up.

#AreaCheckRequestResult
Each run uses unique node names (for example ServerA-k3x9), so it never clashes with existing data or with other people's runs.
